# ResumeIQ screenshot gallery

Keep genuine screenshots from the **current, corrected live UI** here, following the same screenshot-gallery convention as ForgeFlow.

Recommended filenames:

- resumeiq-login.png — login / registration screen
- resumeiq-analysis-inputs.png — resume and job-description inputs
- resumeiq-analysis-report.png — completed match report after the whitespace fix
- resumeiq-aws-lightsail.png — app running under its Lightsail HTTPS URL

Before committing a screenshot:

1. Use the latest deployed version.
2. Remove or blur personal email addresses and resume content.
3. Never show API keys, tokens, passwords, or secret environment variables.
4. Avoid screenshots captured during the earlier text-spacing bug.

After saving screenshots in this folder, embed them in the root README with relative Markdown image links.
